## What I am working on

- **Regime screener (Python, pandas).** A daily equity screener that reads the market regime and scores stocks on seven factors: trend, momentum, volume, theme, gap, sentiment and early-stage strength. It returns plain-English buy, watch and avoid calls with entry levels, stops and position sizes, and an HTML report. Currently private.
- **BFSI risk dashboard (TypeScript, React).** Screens Indian banking and financial stocks on VaR, systemic risk (delta-CoVaR), drawdown and backtest validity. Currently private.
- **Market-risk frameworks.** Stress-testing a basket of large-cap stocks to flag which could break a portfolio, with every input checked twice.
